가장 직관적인 방법.

단축키 하나로 1/2, 1/3 화면 분할.
마우스 없이 당신의 맥을 완벽하게 정리하세요.

SimplePallet은 키보드만으로 Mac 창을 좌우 반, 1/3, 2/3에 배치하는 무료(JPY 0) 창 관리 앱입니다. macOS 기본 Fn + Control + 화살표보다 키 수가 적은 Cmd + 화살표를 기본으로 사용하며, macOS 13 이상의 Apple Silicon 및 Intel Mac을 지원합니다.

SimplePallet이 잘 맞는 사람

macOS 기본 화면 분할만으로 충분한 사람도 있습니다. SimplePallet은 자주 쓰는 배치의 키 수를 줄이거나, 1/3·2/3 너비를 일상적으로 사용하는 사람을 위한 앱입니다.

  • Mac 창을 하루에도 여러 번 나란히 배치한다
  • 마우스 없이 키보드만으로 조작하고 싶다
  • Fn + Control + 화살표보다 간단한 조작을 원한다
  • 문서와 채팅을 1/3·2/3 너비로 배치한다
  • 무료 Mac 창 관리 앱을 찾고 있다
  • 많은 기능보다 기억하기 쉬운 속도를 중시한다

macOS 기본 기능과의 차이

macOS에도 화면 분할 단축키가 있습니다. Fn + Control + 왼쪽/오른쪽 화살표로 활성 창을 좌우 반에 배치합니다. SimplePallet은 이를 Cmd + 왼쪽/오른쪽 화살표로 줄이고 1/3·2/3 배치를 더합니다.

자주 묻는 질문

맥에서 화면을 반으로 나누는 단축키가 있나요?
있습니다. macOS 기본 기능은 Fn + Control + 왼쪽/오른쪽 화살표, SimplePallet은 Cmd + 왼쪽/오른쪽 화살표로 활성 창을 좌우 반에 배치합니다.
SimplePallet은 어떤 사람에게 적합한가요?
Mac 화면을 자주 분할하고 키 수를 줄이거나 1/3·2/3 너비를 쓰는 사람에게 적합합니다. 좌우 반만 필요하다면 macOS 기본 타일링도 좋은 선택입니다.
SimplePallet은 무료이며 안전하게 설치할 수 있나요?
SimplePallet은 완전 무료(JPY 0)입니다. 현재 배포 중인 v1.2 DMG는 Developer ID로 서명되고 Apple 공증을 받았습니다.
개인 정보나 사용 데이터를 수집하나요?
개인 정보나 사용 통계를 수집하지 않습니다. 창 배치는 Mac에서 처리되지만 새 버전을 확인할 때 공개 업데이트 피드에 연결할 수 있습니다.
맥 화면 분할이 안 될 때는 어떻게 하나요?
"시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용"에서 SimplePallet이 켜져 있는지 확인하세요. 이미 켜져 있다면 껐다가 다시 켜세요.
권한 확인이나 자동 실행 설정은 어디서 하나요?
메뉴 막대의 SimplePallet 아이콘을 클릭하면 권한을 확인할 수 있습니다. 같은 메뉴에서 "로그인 시 실행(Launch at login)"도 설정할 수 있습니다.
