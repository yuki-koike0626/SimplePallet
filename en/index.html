SimplePallet is a free (JPY 0) Mac window manager that places windows in left or right halves, one-third, and two-thirds layouts using only the keyboard. Its primary Cmd + Arrow controls use fewer keys than macOS's built-in Fn + Control + Arrow shortcuts, and it supports Apple Silicon and Intel Macs running macOS 13 or later.

Who SimplePallet is for

Some people only need macOS's built-in tiling. SimplePallet is for people who want fewer keys for common placements or regularly use one-third and two-thirds widths.

  • You arrange Mac windows side by side throughout the day
  • You prefer a keyboard-only workflow
  • You want a simpler alternative to Fn + Control + Arrow
  • You use one-third or two-thirds layouts for documents and chat
  • You want a free Mac window manager
  • You value memorable controls over a long feature list

How it differs from built-in macOS tiling

macOS already includes window-tiling shortcuts: Fn + Control + Left/Right Arrow places the active window on the left or right half. SimplePallet shortens that action to Cmd + Left/Right Arrow and adds one-third and two-thirds placements.

Frequently asked questions

Is there a shortcut key to split screen on Mac?
Yes. Built-in macOS uses Fn + Control + Left/Right Arrow, while SimplePallet uses Cmd + Left/Right Arrow to place the active window on either half.
Who should use SimplePallet?
SimplePallet suits people who split their Mac screen often, want fewer keys, or use one-third and two-thirds widths. If left and right halves are all you need, built-in macOS tiling is also a good option.
Is SimplePallet free and safe to install?
SimplePallet is completely free (JPY 0). The current v1.2 DMG is Developer ID signed and notarized by Apple.
Does SimplePallet collect personal or usage data?
It does not collect personal data or usage analytics. Window positioning is processed on your Mac, although the app may contact the public update feed when checking for a new version.
Why is Mac split screen not working?
Open "System Settings > Privacy & Security > Accessibility" and confirm that SimplePallet is turned on. If it is already on, turn it off and on again.
How do I check permissions or set auto-launch?
Click the SimplePallet icon in the menu bar to check permissions. The same menu includes the "Launch at login" setting.
