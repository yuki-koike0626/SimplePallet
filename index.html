macOS標準機能との違い

macOSにも画面分割ショートカットがあり、左右半分は Fn + Control + ← / → で配置できます。SimplePalletは同じ操作を ⌘ + ← / → に簡略化し、さらに1/3・2/3配置を追加します。

よくある質問

Macの画面を半分にするショートカットキーはありますか？
あります。macOS標準では Fn + Control + ← / →、SimplePalletでは ⌘ + ← / → で、アクティブなウインドウを左右半分に配置できます。
SimplePalletはどんな人におすすめですか？
Macで画面分割を頻繁に使い、キー数を減らしたい人や、1/3・2/3幅の配置を使いたい人に向いています。左右半分だけで十分なら、macOS標準機能も選択肢です。
SimplePalletは無料で安全にインストールできますか？
SimplePalletは完全無料（¥0）です。配布中のv1.2 DMGはDeveloper IDで署名され、Appleの公証を受けています。
個人情報や使用状況のデータを収集しますか？
個人情報や使用統計は収集しません。ウインドウ配置はMac内で処理されますが、新しいバージョンの確認時には公開アップデートフィードへ接続する場合があります。
Macの画面分割ができない・機能しない場合は？
まず「システム設定 > プライバシーとセキュリティ > アクセシビリティ」を開き、SimplePalletのスイッチがONか確認してください。すでにONの場合は、一度OFFにしてから再度ONに切り替えてください。
権限の確認や自動起動の設定はどこで行いますか？
画面上部のメニューバーにあるSimplePalletのアイコンをクリックすると権限を確認できます。同じメニューで「ログイン時に起動（Launch at login）」も設定できます。
